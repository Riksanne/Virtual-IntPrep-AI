### Whats this??
basically its a website where a robot voice talks to u and asks interview questions. it uses Vapi (for voice) and Gemini (for thinking). it also uses Nextjs.

### How to Run (imp):
1. clone the repo `git clone https://github.com/Riksanne/virtual-intprep-ai.git`
2. go into folder `cd virtual-intprep-ai`
3. run `npm install` (wait for it to finish)
4. make a file called `.env.local` and put all the keys there (vapi, gemini, firebase). u have to get these yourself sowwy.
5. run `npm run dev` and it will start on localhost 3000.

### Features
- Sign in with firebase
- Talk to AI voice
- Get feedback (Gemini gives u marks)
- Dashboard shows all past interviews
